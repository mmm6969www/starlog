# StarLog

Журнал астрономічних спостережень для клубу аматорів-астрономів.
Навчальний проєкт (ЛР №5): шарувата архітектура за Clean Architecture та командна робота в Git.

## Політика гілок

- main — стабільний код, лише релізи з тегами;
- develop — інтеграційна гілка;
- feature/* — гілки під конкретні задачі (по одній на шар);
- docs/* — зміни документації.

## Коміти

Конвенція Conventional Commits: feat, fix, refactor, test, docs, chore.
